# discord.py-oauth2
Use Discord's OAuth2 effortlessly! Turns the auth code to a access token and the access token into scope infomation.

Documentation is coming soon, don't worry.

## Quickstart
### Installing
This library is on development, if we complete writing this library, you will be able to use pip.
```
pip install discord.py-oauth2
```
